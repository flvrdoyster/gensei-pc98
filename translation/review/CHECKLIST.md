# 번역 전수 검토 체크리스트

근거: `translation/GUIDE.md` + 검수 커밋 히스토리(사용자 교정 전→후 쌍)에서 반복된 교정 패턴.
리포트의 각 지적은 아래 ID를 단다. **[기계]** = 스크립트 전수 검사, **[정독]** = 사람이 읽어야 잡히는 항목.

리포트 표의 `판정` 칸에는 `O`(수용) · `X`(기각, 사유를 짧게) · `△`(수정 수용, 고친 표현)를 적는다. 실제 수정은 에디터에서 한다.

| A5 | 호칭: `님/씨/쨩/군` 붙여 씀, `공`(殿)만 띄어 씀, `ちゃん`→`쨩`(짱 X), `殿`→`공`(님 X) | 3-5, 히스토리(`페톰 님`→`페톰 공`, `짱`→`쨩`) | 기계 |

## S. 화자별 말투 (자동 분석)

각 타이틀 리포트의 "화자별 말투" 절은 아래 규칙으로 뽑았다. 끝 글자로 판정하므로 오검출이 섞일 수 있다.

- **화자**: 화자 줄(`char` 태그) 바로 뒤의 `「` 대사와 이어지는 줄(선행 전각공백)을 그 화자 몫으로 본다. 에디터의 화자 귀속과 같다. 수동 지정 화자가 있으면 그것을 쓴다. `사무라이`·`여자`·`평민`처럼 여러 인물이 쓰는 범용 이름과 나레이션·푯말은 뺀다.
- **문장 끝**: 발화의 마지막 줄, 또는 원문 줄이 종결 어미나 `！？`로 끝나는 줄만 센다.
- **등급**: 존대(합쇼체·해요체·옵니다체·부하체·충청·경상·귀염체), 중간(하오체·하게체·청유 `~ㅂ시다`), 반말. `~네`는 반말과 하게체 양쪽에 쓰여 판정에서 뺀다.
- **상대별로 말투가 갈리는 인물**(영주·상담역·플라즈마)은 습관 이탈 판정에서 뺀다.

| ID | 항목 | 근거 |
|---|---|---|
| S1 | 원문은 높임인데 번역은 반말 | 1-4, 4장 |
| S2 | 반말 화자인데 원문 반말 줄을 높임 | 1-4, 4장 |
| S3 | 원문 높임은 화자의 평소와 같은데 번역 등급만 평소와 다름 | 1-4 |
| S4 | 한 화자 안에서 같은 원문 어미가 다른 등급으로 번역됨 | 1-4, 9-2 |
| S5 | GUIDE 어미 매핑표(8-1 부하, 9-2 에도 말투)와 다른 어미 | 8-1, 9-2 |
| S6 | 화린 원문 `~ですわ/~ますわ`(`ね` 없음)를 `~네요`로 옮김 | 9-1 |
