# 환세 시리즈 한글화 번역 지침

문서 구성: **1~5장은 시리즈 공통 규칙**, **6장부터는 타이틀별 정보**(희담 → 풍광전 → 쾌도전 → 포물장 → 희담 외전 → 패유기).
실제 번역 작업 시에는 공통부를 숙지한 뒤 해당 타이틀 섹션을 펴놓고 진행한다.

---

## 1. 작업 원칙

- **원문 충실** — 원문에 없는 내용을 더하지 않고, 있는 내용을 빼지 않는다
- **자연스러운 한국어** — 직역투를 피하고 한국어 어순·표현으로 옮긴다

### 1-1. 글자수

게임 버퍼 제약으로 **번역문 글자수가 원문 글자수를 넘을 수 없다**. 모든 판단의 전제가 되는 물리 제약이다.

- 모든 문자(한글, 일본어, 영숫자, 공백)를 **1자**로 계산 (`len(line)` 기준)
- 여유가 있으면 줄이지 말고 원문의 의미·뉘앙스·리듬을 최대한 살린다
- 초과할 때만 압축한다 — 의역(1-2), 행 재배열(1-3) 순으로 시도

### 1-2. 의역 허용 기준

직역 우선. 아래 중 하나에 해당할 때만 의역한다.

1. 직역이 글자수를 초과할 때
2. 일본식 표현이라 한국어로 부자연스러울 때
3. 현대 독자에게 어색한 표현일 때

의역/직역 판단 원칙:

- **판단 근거는 사전 의미가 아니라 게임 내 실제 연출·상황이다.** 예: `ブッとばす`가 실제로 날려버리는 연출이면 비유적 '때려눕히다'가 아니라 글자 그대로 '날려버리다'
- **직역이 한국어로 성립하는 관용구는 한국어 관용구로 갈아끼우지 않는다.** 예: `根に持つ`→`마음에 담아두다`(직역 성립) — '뒤끝 부리다' 치환 금지. 관용 대 관용이 정답은 아니다
- **압축할 때도 핵심 어휘는 직역으로 지킨다.** 지시어·조사 등 군더더기부터 덜어낸다
- **관용구를 압축으로 깨뜨리지 않는다.** `식은 죽 먹기`를 '식은 죽'으로 줄이면 관용이 성립하지 않는다 — 여유가 있으면 완성형 유지
- **무거운 표현은 의미 보존을 전제로 긍정 전환해 수위를 낮출 수 있다.** 예: `一家心中しなくてすむ` → `일가족이 살 수 있어`

### 1-3. 행 재배열

원문의 행 구조는 따르지 않아도 된다.

- 행을 합치거나 쪼개고, 행 순서를 바꿔 자연스러운 흐름과 리듬을 만들 수 있다
- 단, 한 행이 다음 행을 수식하는 구조면 호응 관계가 깨지지 않게 유지한다
- **행마다 독립적으로 종결시키는 버릇 금지** — 원문이 줄마다 끊겨도, 한국어는 관형절 등으로 줄을 넘겨 한 문장으로 엮는 게 자연스러울 때가 많다
- 두 줄에 걸친 대사는 원문 행 순서에 매이지 말고 한국어 어순으로 재배분한다: `天才だね/あたいって` → `나는 역시/천재야!`
- 조사는 다음 줄과 호응하도록 고른다: `이 정도 문도` ← 뒷줄 `못 부수냐?`와 호응

### 1-4. 말투·톤 일관성

- **기존 캐릭터** — 확정 번역(`translation.json`의 `kr` 값)이 최우선 기준. 말투표(4장·각 타이틀 섹션)는 가이드라인이며, 둘이 충돌하면 확정 번역을 따르고 말투표를 갱신한다
- **신규 화자** — 원문 어미에서 힌트를 읽는다: `のぉ/じゃ`→노인, `わよ/わね`→여성, `ぜ/だぜ`→남성 구어 등. 말투를 정하면 해당 말투표에 추가한다
- 존댓말↔반말 전환이 있는 캐릭터는 상대·상황별 전환 패턴을 기존 번역에서 파악한다
- 같은 단어·표현이 **같은 맥락에서** 반복되면 기존 확정 번역과 동일하게 통일한다. 맥락이 다르면 변주 허용 (1-5 서법, 3-8 맥락 분기 참조). 단 고유명사(아이템·기술·지명 등)는 맥락 무관하게 확정 표기를 반드시 따른다
- 장면 단위로도 일관성을 본다 — 같은 장면의 주변 대사 톤과 맞춘다
- **받아치는 대사는 같은 단어로 맞춰 대구를 살린다**: "재밌네요" → "안 재밌어!"로 받아야 대비가 산다 ("안 웃겨"로 풀면 대구가 죽음)
- 말장난은 원문의 반복 횟수를 채우는 것보다 **자연스러운 받아치기 한 번**이 우선이다

### 1-5. 서법 보존

원문의 서법(정중·존경·추측·납득 등)을 거친 쪽으로도 정중한 쪽으로도 평탄화하지 않는다.

- 추측(`らしい`)·납득 등의 서법은 어미 일관성이나 압축보다 우선해 살린다
- **없는 존경을 덧칠하지 않는다** — 단순 정중 과거(`つきました`)는 `했군요`지 `하셨군요`가 아니다
- 인물 간 상하관계(殿/공 호칭)와 타인의 죽음 언급은 높임에 반영한다: `死んだお母さん` → `돌아가신 어머니`
- 정중체 화자라도 혼잣말로 납득하는 맥락이면 `그렇군`이 맞다 — 어미 일관성보다 서법이 우선

## 2. 포맷 규칙

### 2-1. 문자 변환

| 원문 | 번역 | 예시 |
|------|------|------|
| 전각 숫자 `１２３` | 반각 `123` | `データ１` → `데이터1` |
| 전각 영문 `ＭＰ`, `ＳＰ` | 반각 `MP`, `SP` | `消費ＭＰ１０` → `소비MP10` |
| 전각 `！？` | 반각 `!?` | |
| 전각 공백 `　` | 일반 공백 | |

### 2-2. 괄호·기호

- 대화 괄호 `「」`, 속마음·읽기 괄호 `『』` → 그대로 유지 (여는 괄호 `「`만 있는 행도 그대로)
- `【】` `〔〕` 아이템 괄호 → 그대로 유지: `〔鋼鉄の剣〕` → `〔강철검〕`
- `・`(가운뎃점) → 그대로 유지: `お・ま・け` → `서・비・스`
- 첫 줄의 `「`와 행머리 전각공백도 글자수 버퍼에 포함된다 — 번역에 활용 가능

### 2-3. 정렬용 공백

메뉴의 정렬용 공백은 유지:
`攻　撃` → `공 격`, `魔　法` → `마 법`, `逃げる` → `도 주`

### 2-4. 적·아이템 이름 `/` 포맷

적·아이템 이름은 필요시 음절마다 `/`로 분리하여 고정폭 버퍼에 대응한다. 풍광전·희담에서 공통으로 사용.

- **기준**: 한글 **4자 이상**이면 슬래시 분리, 3자 이하는 그대로. (희담·풍광전 모두 4~5자 적 이름이 있어 슬래시 분리 대상이 많음)
  - 희담: `소서러`(3자) → 그대로, `프테시스`(4자) → `/프/테/시/스`, `머신에이프`(5자) → `/머/신/에/이/프`
  - 풍광전: `スライム` → `/슬/라/임`, `リビングデッド` → `/리/빙/데/드`
- **아이템도 동일**: `リフレッシュの水` → `/리/프/레/시/워/터`
- **예외**: 약칭으로 줄여 글자수를 맞추는 경우도 있음 — `ブレード村正`(블레이드 무라마사) → `B.무라마사`

### 2-5. 더듬음 처리

더듬는 첫 음절(원문 `ま　待って`, `そ　そんな` 등)은 **번역문 첫 단어의 첫 음절을 반복**해 옮긴다. 일본어 음절이 아니라 한국어 단어 기준이다.

- `ま　待ちやがれ` → `기 기다려`, `そ　そんなバカな` → `마 말도 안 돼`
- 더듬음 사이 전각공백은 일반 공백으로 (2-1)

## 3. 이름·용어·표현

이름류(기술·아이템·적 이름·지명·상호)는 글자수 제약으로 **띄어쓰기 없이 붙여 쓴다**: `날카로운발톱`, `독바른검`, `요정연회정`.

### 3-1. 캐릭터 이름 (카타카나 → 한글)

- 장음 `ー` 생략: `アターホー` → `아타호`, `ファーリン` → `화린`, `シーラ` → `실라`
- 축약 가능: `ペトゥム` → `페톰`, `スマッシュ` → `스마슈`

### 3-2. 기술·주문명

- 한자 기술명 → 한자음 직독: `脳天砕` → `뇌천쇄`, `烈風飛翔` → `열풍비상`, `白刃一閃` → `백인일섬`
- `の呪文` → `의주문`: `爆炎の呪文` → `폭염의주문`
- 예외: 
  - 풍광전에선 `の呪文`과 앞 글자를 조합하는 식으로 구성된 이름이라 직역을 썼으나,
    희담에선 통으로 기술 이름이라 한국어를 살려 `불꽃주문`, `얼음주문`, `번개주문`으로 처리.
  - `대염의주문`→ 풍광전에선 유일한 전체공격기로 구분이 필요해 기존 이름을 그대로 직역, 
    희담에선 다른 기술과 차이가 없어 급을 맞추어 `불꽃주문`으로 처리.

### 3-3. 아이템명

- 의미 번역 우선: `薬草` → `약초`, `鎖かたびら` → `사슬갑옷`, `毒ぬりの剣` → `독바른검`
- 외래어 아이템은 음차: `ロングスピア` → `롱스피어`, `リフレッシュの水` → `리프레시워터`
- 금액 단위: `５０Gold` → `50G`
- 이름 확정은 이 규칙, 게임 화면 표시 시 슬래시 분리는 2-4를 따른다

### 3-4. 적·NPC 이름

- 한자 이름 → 뜻 번역: `用心棒` → `경호원`, `盗賊親衛隊` → `도적친위대`
- 역할 기반 이름에 `역` 접미사: `見回り` → `순찰역`, `見張り` → `감시역`
- 카타카나 몬스터 → 음차: `スライム` → `슬라임`, `リッチー` → `리치`
- 창작 적응 허용: `岩喰い` → `바위귀`, `猫耳娘` → `야옹귀` (`귀` = 괴물 뉘앙스)
- 일반 지칭: `モンスター` → `몬스터` (음차 통일), `魔獣` → `마수`

> **각 타이틀 섹션의 '적 이름' 표는 전투 화면에 이름이 표시되는 전투 대상의 확정 목록이다.**
> 임의로 항목을 추가하지 않는다 (이미 있는 항목의 용어 통일 정정만 허용).
> 비전투 등장 캐릭터의 이름은 각 타이틀의 '고유 용어'에 둔다.

### 3-5. 일반 호칭·지칭

호칭 접미사 `~님`/`~씨`/`~쨩`/`~군`은 앞말에 붙여 쓴다(글자수 버퍼 1자 확보): 스마슈씨, 장로님, 화린쨩. 
단 `~공`(殿)만 예외로 띄어 쓴다(일반 호칭이 아니라 붙이면 어색): 화린 공, 페톰 공.

| 원문 | 번역 | 비고 |
|------|------|------|
| 殿 | 공 | 격식 있는 호칭 |
| 様 | 님 | |
| さん | 씨 / 님 | 말투에 따라 선택 |
| ちゃん | 쨩 | 애칭 |
| おぬし | 그대 / 자네 | 격식체(무사 말투) 화자 → `그대`, 그 외 → `자네`. 복수 `おぬしら` → 자네들/너희 |
| ダンナ | 나리 / 남편 | 영주·주인 맥락 → 나리, 부부 맥락 → 남편 |
| 兄貴 | 형님 | 부하·꼬붕이 두목 형님을 부를 때 |
| ヤツ | 녀석 / 놈 | 적대 정도에 따라 |
| 姫 / 女王 | 공주님 / 여왕님 | 단독인 경우 '님'을 포함하도록 |

### 3-7. 웃음소리·감탄사

- **웃음소리는 음차 통일**: `ケケケ`→`케케케`, `キキキ`→`키키키`, `ハハハ`→`하하하`, `ホホホ`→`호호호`, `フフフ`→`후후후`, `イヒヒ`→`이히히`, `ヒッヒッヒ`→`힛히히`
- 노인(장로 등) `ふぉふぉ` → `흐흐` / `후후후`
- **감탄사**: `おお`→`오/오오`, `ええっ`→`엣`, `くっ`→`흡`, `ちっ`→`쳇`, `うむ`→`음/으음`, `ふっ`→`훗`(코웃음), `あら`→`어머`(여성), `ちくしょう`→`제기랄/젠장`, `なるほど`→`과연/그렇군`, `んが!`→`으앗!/윽!/억!`(상황에 따라)
- 늘임 비명은 한국어 늘임으로 살린다: `しまったぁ〜` → `아차차~`
- 타격 등 효과음도 짧은 의성어로(`ボカッ`→`퍽`). 개체·상황 구분이 필요하면 표기를 전부 다르게 한다 (동물 울음 개체별 표기와 동일 원칙)

### 3-8. 관용·속담·표현

직역하면 어색하거나 글자수가 넘치는 관용 표현·어휘. 의미·길이 우선으로 옮긴다.

| 원문 | 한국어 | 비고 |
|------|------|------|
| 私腹をこやす | 뒷돈을 챙기다 | '사복을 채우다' 아님 |
| 食わずぎらい | 편식 | 글자수 제약 시 |
| アサメシ前 | 식은 죽 먹기 / 껌이다 | |
| みかけだおし | 겉만 번지르르 | |
| こじあける | 비틀어 따다 | |

### 3-10. `でござる`체 (사무라이 말투) → 하오체

`でござる`체 사무라이 말투는 **하오체**로 옮긴다 (국내 더빙 선례 기준). 작품 불문 공통 — 희담 무라마사 등.

- **평서·단정**: `~하오 / ~이오 / ~소이다 / ~것이오`, 명령·청유 `~하시오`
  - `とれたてでござる` → `갓 따온 것이오`, `頼りにされているのでござる` → `신임받고 계시오`
- **의문 `でござるか`**: `~이오? / ~이옵니까` (`ござるか` → `이오?`)
- **혼잣말 감탄**(`~なぁ / でござるなあ`)도 하오체로 종결: `よく効くなぁ` → `참 잘 듣소`, `ホッとするでござるなあ` → `마음이 놓이오`

**금지·주의**
- `~구려` 금지 — 노인 어미(개 장로 등)라 사무라이엔 안 씀
- `~오이다 / ~오이까` 금지 — 어순 뒤집힌 비문. `でござる`→`~이오`, `でござるか`→`~이오?/~이옵니까`
- `~도다 / ~는도다` 지양 — 고풍 과잉. 평서는 하오체로
- 혼잣말도 `~는구나`(현대)·`~는도다`(고풍) 둘 다 지양 → 하오체 종결

## 8. 쾌도전

### 8-1. 캐릭터 말투

주연의 기본 말투는 4장 참조. 아래는 쾌도전 특이사항과 쾌도전 전용 캐릭터.

**주연 — 쾌도전 특이사항**

- **알리바바** (주인공): 자뻑 개그가 핵심("천재인 나", "드디어 내가 주연!"). `女盗賊`→여도적, 「おねえちゃん」→누나.
- **페톰**: 차분한 존댓말 기조이나, 알리바바 상대로는 가끔 **반존대로 흘린다**(`~군/~것 같아`). 알리바바와 '대사·분량' 메타개그를 주고받음. 주 동행.
- **스마슈**: 경박한 반말 공통. 알리바바와 '주역' 다툼 개그.
- **다리오스**: 직선적 반말 공통. 돼지 `마르가리타` 관련 장면 톤 주의 (4장 비고 참조).

**쾌도전 전용 캐릭터**

- **마인**(램프 요정, 남성): 마지못해 시중드는 시니컬한 공손체. 격식 어미 `~옵니다`/`~시옵소서`, 체념하면 격식 풀고 코믹하게(`일이니까요…`). 소환 첫 등장에서만 음절을 늘려 말함 — `お〜よ〜び〜で〜` → `부~르~셨~습~니까`, `わ〜た〜し〜は〜` → `저~는~`. 평상시엔 늘리지 않음.
- **암거래상**(`闇の商人`): 정중한 존댓말 + 능청(`~겠죠/~일지도 몰라요/~안 파시겠습니까?`). 부하 말투 아님.
- **도적단수령**(보스): **비꼬는 정중체** — 거만+여유의 존댓말에 반어가 특징(침입자를 `손님`, 공격을 `대접`이라 부름). 부하에게도 정중을 갖추면서 실은 명령한다. 분노·공격 단계에서도 정중체를 유지한 채 위압을 싣고(`くらいなさい`→`받으시죠`), **결정적 실수·패배 순간에만 격식이 무너진다**(반말 비명) — 이 붕괴가 캐릭터 개그의 핵심. 혼잣말은 반말 허용.
- **플라즈마**(`블레이드 플라즈마`, 추격자): 풍광전 보스 재등장. **상대별 톤 구분** — 용의자·도적 추궁 시 위압적 격식(`~다/군`, "녀석은 분명 여기 있다!"), 페톰 등 존중 상대엔 정중(`~소/하오/지요`). 도리어 **추궁당하면 `아 아니/그 그렇군` 쩔쩔맴**(개그).
- **오사카벤 NPC**: 원문 오사카 사투리 → **경남 여성 말투 현대형**(`~이가? / 왔노? / ~ㄴ데 / 뭐고~ / 진짜가?`). ※부하 `でガンス`의 우직한 경상 사투리와 결이 다름(이쪽은 현대 여성 톤).
- **마을 호객 NPC**(장사꾼): 구어체 `~더라구`, 축약(`가게는`→`가겐`).

**도적단 부하**

졸개가 여러 명이고 말버릇이 제각각이다. **원문 어미를 기준으로** 한국어 어미를 배정한다. **같은 원문 어미라도 캐릭터·성격이 다르면 다른 한국어 어미**로 가도 된다.

| 식별 어미(원문) | 한국어 어미 |
|------|------|
| `でさあ` / `ですぜ` | **~임다 / ~슴다** (의문 `~슴까`) |
| `でやんす` / `やせん·です` | **~입죠 / ~습죠** |
| `でヤス` / `やした` | **~입니다요 / ~습니다요** (의문 `~습니까요?`) |
| `くだせぇ` | 다급할 땐 **~줍쇼** (`助けてくだせぇ`→`살려줍쇼`) |
| 문말 `っち` | **~용** (부하 중 혼자 귀여운 말투 — 개그 포인트) |
| `でガンス` / `でゴワス` | **~심더 / ~니더** (경상 사투리, 의문 `~습니꺼?`. `억수로`·`갑심더`·`우짤`·`아입니꺼` 등) |

- 번역 예: `…でさあ`→`…임다`, `情報は入ってきてやせん`→`정보는 없습죠`, `わかりやした`→`알겠습니다요`, `あるらしいですっち`→`있는 것 같아용`, `金額がでかいでガンス`→`금액이 억수로 큽니더`
- `ですかい / かい？`는 부하 전용이 아니라 일반 NPC 의문형이므로 부하 말투로 취급하지 않는다.

## 9. 포물장

### 9-1. 캐릭터 말투

주연(화린·스마슈·유리와카마루)은 4장 참조. 아래는 포물장 특이사항·전용 캐릭터.

**주연 특이사항**

+ **화린**
원문에 아가씨 종조사 `わ`(`~ですわ`/`~ですわね`/`~かしら`)가 강하게 깔림. 4장 기본 어미를 따르되 포물장에선 우아함을 살린다 — 단, 다음을 지킨다:
  + **종결 기본값은** `~어요`(안심이에요/놀라워요/생각도 못 했어요). `~네요`를 기본으로 깔지 말 것. `~ですわ`/`~ですわね`를 기계적으로 `~네요`로 옮기는 것은 반복 교정 대상.
  + `~네요`는 **감탄·동의가 또렷한 줄에만**(강하시네요 등). 한탄·애정 섞인 자리(정말 어쩔 수 없는 사람들이에요…)는 `~네요`가 어감을 무겁게 하므로 `~이에요`.
  + **혼잣말로 깨닫는·납득하는 자리**는 `~군요`/`~겠어요`(이게 인도의깃이군요 / 강한 힘을 가지셨겠죠). 확인·동의는 `~네요`. (1-5 서법 연동)
  + **적·동물·요괴에게도** `さん`**(씨)을 붙이고 높임을 유지하는 천연 성격**: 도둑씨·요괴씨·텐구씨, 적 타마모에게도 `강하시네요`. 단 동물+씨가 어색하면(`カニさん` 등) 글자수·어감 보아 생략 가능.
+ **유리와카마루**
4장 어미(`~다`, `~군`, `~나`, `~지`, `~야`, `~네`, ~`겠지`, `~인가`)를 따르되, `~군`을 기본값으로 깔지 말 것(반복 교정 대상). `~군`은 깨달음·발견 자리에만. 나머지는 자리별로 갈라 쓴다 — 평서·단정 `~다`/`~야`, 납득·동의 `~지`, 가벼운 감상 `~네`/`~인데`, 추측 `~겠지`/`~ㄴ 듯해`, 의문 `~나`/`~인가`. 원문 서법·맥락 우선, `〜てしまう`는 한 동사로 살린다. 남장 여검사라 평소엔 남자 말투지만, 당황·동요로 말투가 무너지는 때를 잘 살린다. 
1인칭 `おれ`는 평소 '나'(남장이라도 '저'로 낮추지 않음). 단 부친(영주) 앞 격식 보고(엔딩 평가 등)에선 '저'+`~습니다` — `나… 아니 저도` 식 자기교정으로 살린다. 
+ **스마슈**
4장과 동일. 호색한 개그 톤 유지.

**전용 캐릭터**

| 캐릭터 | 정체 | 어미 예시 | 비고 |
|--------|------|----------|------|
| **여우민족 장로**(キツネの長老) | 여우민족 노장로. 능청·짓궂음 | ~네, ~지, ~로세, ~구먼, ~겠는가?, ~게나, ~주게, ~허허 | **포물장 전용 배정**(희담 개민족 장로와 구분). 1인칭 `わし`→`나`. 능청·놀림조(`人が悪い`/`スケベ` 면) 살릴 것 |
| **신쥬로**(シンジュウロウ) | 유리와카마루의 형. 텐쇼류 거합 검사, 방탕아 | ~다, ~군, ~마라 | 호탕한 형 말투. 웃음 `はっはっは`→`하하하` |
| **타마모**(タマモ) | 구미호(九尾), 진 보스 요괴 | ~해!/~이야!(`わ`/`よ`), ~네!(`わね`/`ねぇ`), ~는 거야?(`のかい`, 들이대기) | **자뻑·표독한 드센 여성체**가 본색. `あんた`→너. 자뻑 외래어(`キュート`/`ウルトラセクシー`)는 음차 유지. **~다/~지/~겠다는 보스 본색 드러낼 때** 오만한 단정체. `ちくしょ〜`→`제기랄`(3-7) |
| **용녀**(乙姫) | 용궁 공주(우라시마 상자 모티브) | ~에요, ~네요, ~답니다 | 우아한 정중 아가씨말. `あら`→`어머` |
| **영주**(殿様) | 유리와카마루·신쥬로의 부친, 군주 | 상대별 분기 — 자식(유리·신쥬로): ~다 / ~느냐 / ~거라 / ~게냐 · 가신·협력자(화린 공·스마슈 공): ~네 / ~군 / ~게나 / ~않겠나 · 장로 등 격식 상대: ~소 / ~이오 / ~외다 | 자식엔 반말·위엄, 가신엔 하게체, 장로엔 하오체로 갈린다. 余(과인) 나오는 줄만 과인 위엄(`만족스럽도다`). |
| **상담역**(相談役) | 영주의 가신, 노년 남성. 밀정과 담당 | 영주께: ~옵니다 / ~사옵니다(옵니다체) · 주인공들에게: ~네 / ~게나 / ~나? / ~구먼(하게·노인체) | 자칭 `소인`. 유리와카마루 정체를 안 뒤엔 격식 ↑(옵니다·하오). |

### 9-2. 에도 말투

포물장 본문에 **실제 등장하는** 에도풍 어미·표현 한정 인벤토리(빈도=원문 등장수).
같은 원문 어미는 **가급적 같은 한국어**로 옮겨 일관성 유지.
한국어에 대응 어미가 부족한 경우 방언 어형을 빌려 어미 종류를 구분 — 방언은 캐릭터 지역색이 아니라 **어미 매핑 수단**이다.

**종결·단정**

| `べらぼうめ` | 5 | 바보같긴 | 위와 동일 — 센 욕으로 옮기지 말 것 |

## 10. 희담 외전

### 10-1. 캐릭터 말투

주연급 등장인물은 스마슈·화린·몽몽·아타쿠. 스마슈·화린은 4장, 개민족 장로는 6-1(희담) 참조.

| 캐릭터 | 말투 | 어미 예시 |
|--------|------|----------|
| **몽몽** | 동굴 수호신, 불명. 어린아이 같은 말투. `~もん`는 예외 없이 `~몽`으로 통일 | ~몽!, ~이다몽!, ~하다몽! |
| **아타쿠** | 개민족, 젊은 남성. 스마슈의 사형. 냉소적이고 오만한 악당. 단언하는 반말 | ~군, ~지, ~라고 |
