# 환세 시리즈 한글화 번역 지침

---

## 1. 기본 방침

- **원문 충실** — 원문에 없는 표현을 임의로 추가하지 않는다
- **자연스러운 한국어** — 표현과 어순은 한국어에 맞게
- **글자수** — 여유가 있으면 원문의 의미·뉘앙스·리듬을 최대한 살린다. 넘치기 시작할 때만 줄인다
- 여러 행이 이어질 때 행 순서를 재배열해 리듬을 살릴 수 있다
- 한 행이 다음 행을 수식하는 구조면 호응 관계를 유지한다

### 1-1. 글자수 규칙

- 모든 문자(한글, 일본어, 영숫자, 공백)를 **1자**로 계산 (`len(line)` 기준)
- 번역문 글자수 ≤ 원문 글자수면 OK

### 1-2. 의역 허용 기준

직역이 아래 중 하나라도 해당하면 의역 허용. 아니면 직역 우선.

1. 글자수를 초과할 때
2. 일본식 표현이라 한국어로 자연스럽지 않을 때
3. 현대 독자에게 어색한 표현일 때

### 1-3. 행 재배열

원문 행 구조를 반드시 따르지 않아도 됨. 글자수 초과 시 행을 합치거나 쪼개서 자연스러운 흐름 우선.

## 2. 말투·어미 지침

### 2-1. 어미에서 말투 힌트 파악

`のぉ / じゃ` → 노인, `わよ / わね` → 여성, `ぜ / だぜ` → 남성 구어 등
어미에서 성별·나이·성격을 읽고 한국어 어미로 매칭.

## 4. 톤 일관성 유지

각 작품의 `translation.json`에 이미 확정된 번역(`kr` 값)이 존재한다. 새로운 대사를 번역할 때 아래를 지킨다.

### 4-1. 원칙

- **같은 캐릭터의 기존 번역 어미·말투를 먼저 확인**한 뒤 번역한다
- 캐릭터 말투표(2-2, 2-3)는 기본 가이드라인이고, 실제 확정된 번역이 더 우선한다
- 확정 번역과 말투표가 충돌하면 확정 번역 쪽을 따르고, 필요 시 말투표를 갱신한다

### 4-2. 확인 방법

1. 해당 캐릭터의 기존 확정 번역에서 어미 패턴 확인
2. 같은 장면·맥락의 주변 대사 톤과 일관성 유지
3. 존댓말↔반말 전환이 있는 캐릭터는 상대·상황에 따른 전환 패턴도 기존 번역에서 파악

### 4-3. 주의사항

- 같은 단어·표현이 반복 등장하면 기존 확정 번역과 동일하게 통일
- 아이템명·기술명·지명 등 고유명사는 이미 확정된 표기를 반드시 따른다
- 새 캐릭터가 등장하면 말투를 결정한 뒤 말투표에 추가한다

## 5. 포맷 규칙

### 5-1. 문자 변환

| 원문 | 번역 | 예시 |
|------|------|------|
| 전각 숫자 `１２３` | 반각 `123` | `データ１` → `데이터1` |
| 전각 영문 `ＭＰ`, `ＳＰ` | 반각 `MP`, `SP` | `消費ＭＰ１０` → `소비MP10` |
| 전각 `！？` | 반각 `!?` | |
| 전각 공백 `　` | 일반 공백 | |

### 5-2. 괄호·기호

- `「」` 대화 괄호 → 그대로 유지
- `【】` `〔〕` 아이템 괄호 → 그대로 유지: `〔鋼鉄の剣〕` → `〔강철검〕`
- `・`(가운뎃점) → 그대로 유지: `お・ま・け` → `서・비・스`

### 5-3. 정렬용 공백

메뉴에서 2자 한자를 4칸에 맞추는 공백은 유지:
`攻　撃` → `공 격`, `魔　法` → `마 법`, `逃げる` → `도 주`

### 5-4. 적·아이템 이름 `/` 포맷 (시리즈 공통)

적·아이템 이름은 필요시 음절마다 `/`로 분리하여 고정폭 버퍼에 대응한다. 풍광전·희담에서 공통으로 사용.

- **기준**: 한글 **4자 이상**이면 슬래시 분리, 3자 이하는 그대로. (희담·풍광전 모두 4~5자 적 이름이 있어 슬래시 분리 대상이 적지 않음)
  - 희담: `소서러`(3자) → 그대로, `프테시스`(4자) → `/프/테/시/스`, `머신에이프`(5자) → `/머/신/에/이/프`
  - 풍광전: `スライム` → `/슬/라/임`, `リビングデッド` → `/리/빙/데/드`
- **아이템도 동일**: `リフレッシュの水` → `/리/프/레/시/워/터`
- **예외**: 약칭으로 줄여 글자수를 맞추는 경우도 있음 — `ブレード村正`(블레이드 무라마사) → `B.무라마사`

## 6. 이름·용어 번역 규칙

### 6-1. 캐릭터 이름 (카타카나 → 한글)

- 장음 `ー` 생략: `アターホー` → `아타호`, `ファーリン` → `화린`, `シーラ` → `실라`
- 축약 가능: `ペトゥム` → `페톰`, `スマッシュ` → `스마슈`

### 6-2. 기술·주문명

- 한자 기술명 → 한자음 직독: `脳天砕` → `뇌천쇄`, `烈風飛翔` → `열풍비상`, `白刃一閃` → `백인일섬`
- `の呪文` → `의주문`: `爆炎の呪文` → `폭염의주문`
- 예외: 
  - 풍광전에선 `の呪文`과 앞 글자를 조합하는 식으로 구성된 이름이라 직역을 썼으나,
    희담에선 통으로 기술 이름이라 한국어를 살려 `불꽃주문`, `얼음주문`, `번개주문`으로 처리.
  - `대염의주문`→ 풍광전에선 유일한 전체공격기로 구분이 필요해 기존 이름을 그대로 직역, 
    희담에선 다른 기술과 차이가 없어 급을 맞추어 `불꽃주문`으로 처리.


### 6-3. 아이템명

- 의미 번역 우선: `薬草` → `약초`, `鎖かたびら` → `사슬갑옷`, `毒ぬりの剣` → `독바른검`
- 외래어 아이템은 음차: `ロングスピア` → `롱스피어`, `リフレッシュの水` → `리프레시워터`
- 금액 단위: `５０Gold` → `50G`

### 6-4. 적·NPC 이름

- 한자 이름 → 뜻 번역: `用心棒` → `경호원`, `盗賊親衛隊` → `도적친위대`
- 역할 기반 이름에 `역` 접미사: `見回り` → `순찰역`, `見張り` → `감시역`
- 카타카나 몬스터 → 음차: `スライム` → `슬라임`, `リッチー` → `리치`
- 창작 적응 허용: `岩喰い` → `바위귀`, `猫耳娘` → `야옹귀` (`귀` = 괴물 뉘앙스)

## 10. 작품별 고유 정보

### 10-1. 풍광전 

- 적 이름에 `/` 음절 분리 포맷 사용 (5-4 참조)
- `ニイちゃん` → `형씨` (캐릭터 간 호칭 현지화)
- 효과음 현지화: `ヒャヒャヒャ` → `햐햐햐`, `ブゥ！` → `꿀!`
- 고어 표현 현지화: `ひぃ…ふぅ…みぃ…` (고어 세기) → `하나… 둘… 셋…`

### 10-2. 희담 

- **〇〇の民** → **〇〇민족**: `犬の民`→`개민족`, `キツネの民`→`여우민족`, `トラの民`→`호랑이민족`
- **〇〇の民の長** → **〇〇민족 족장** (원문에 長老가 나오면 장로, 그 외엔 족장으로 통일)
- **封印の民 / 封印の一族** → **봉인 일족**: 종족이 아니라 봉인을 지키는 역할 집단이므로 `민족`이 아닌 `일족`으로 구분
- `おぬし` 번역 분기: 무라마사 → `그대`, 장로·기타 → `자네` (3장 참조)
- 적·아이템 이름 슬래시 분리 포맷 (5-4 참조)

### 10-3. 쾌도전 

#### 화자 말투

- **알리바바** (주인공, 여성): 1인칭 `あたい`→`나`. 보이시한 거친 반말 + 자뻑("천재인 나", "드디어 내가 주연!"). `女盗賊`→여도적, 「おねえちゃん」→누나. 원문에 `俺`로 나와도 '나'로.
- **마인**(램프 요정): 마지못해 시중드는 시니컬한 공손체(`~옵니다`/`~습니다`). 소환 첫 등장에서만 음절을 늘려 말함 — `お〜よ〜び〜で〜` → `부~르~셨~습~니까`, `わ〜た〜し〜は〜` → `저~는~`. 평상시엔 늘리지 않음.
- **도적단 수하**: 졸개가 여러 명이고 **각자 다른 캐릭터**다. 원문 말버릇(어미)으로 캐릭터를 식별하되, 한국어 어미는 그 캐릭터 성격에 맞춰 배정한다. **같은 일본어 어미라도 다른 캐릭터면 다른 한국어 어미**로 가도 된다.

확정된 배정:

| 캐릭터 | 식별 어미(원문) | 한국어 어미 |
|------|------|------|
| 수지 담당 | `でさあ` (회계 보고 맥락) | **~임다 / ~슴다** (의문 `~슴까`) |
| 정보 담당 (A·B) | `でやんす` / `やせん·です` (정보 보고 맥락) | **~입죠 / ~습죠** |
| 아지트 지킴이 | 문말 `っち` | **~입니다요 / ~습니다요** |

- 번역 예: `…でさあ`→`…임다`(수지), `情報は入ってきてやせん`→`정보는 없습죠`(정보), `わかりましたっち`→`알겠습니다요`(아지트)
- **정정 대상**: 수지 보고인데 입죠로 된 `570G입죠`는 `570G임다`로, 정보 담당 A·B의 `있답니다요`·`있어요`는 입죠/습죠로 통일.
- 아직 어미 미배정 캐릭터: `手下１`(`でヤス`), 던전 동행 부하(`でガンス`). 해당 대사 번역 시 아래 예비 팔레트에서 골라 배정한다.
- `ですかい / かい？`는 수하 전용이 아니라 일반 NPC 의문형이므로 수하 말투로 취급하지 않는다.
- `お頭` → `두목`

#### 수하 어미 예비 팔레트

새 졸개·하인 캐릭터가 등장하면 성격에 맞춰 아래에서 골라 쓴다 (위 확정 3종과 겹치지 않게).

| 갈래 | 어미 | 느낌 |
|------|------|------|
| 사극 하인체 | `~굽쇼/~ㅂ쇼`, `~깝쇼/~ㄹ깝쇼`(의문), `~올시다`, `~ㄴ뎁쇼` | 비굴·굽신. 예: "아니굽쇼", "어찌 할깝쇼?" |
| 시골 사투리 | `~유/~구먼유`(충청), `~당께`(전라), `~다카이/~예`(경상) | 어수룩한 촌뜨기 졸개 |
| 어수룩·귀여움 | `~당/~ㅁ다`, `~ㅎ다요/~ㅆ다요` | 덜떨어진 졸개. 다요체는 희담 수하가 이미 사용 |
| 말버릇 tic | `~말입죠/~말임다` | 어미에 군더더기. 예: "신경 좀 쓰시지 말임다" |

### 10-4. 패유기

- 마작 게임이므로 마작 용어 통일: 리치, 쯔모, 론, 펑, 텐파이, 나가리, 도라
- 스킬명은 한자 직독 또는 음차 유지: `맹호일발권`, `도라폭진`, `수경`, `크리티컬`, `라스트 찬스`
- 마유(눈썹개)는 히든 보스로, 대사 없이 짖는 소리만 사용
